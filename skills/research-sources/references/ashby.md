# Ashby

`ashby` uses the board name in the employer's careers link.

- **Search** returns listed roles in API order. Filter by title words, team or department, primary or secondary location, and last publication date (UTC). `text` gives one line of available facts: locations, workplace type, employment type, team and employer-published pay.
- **Read** puts those facts above the description in `text`.

A board is a snapshot of current postings. It has no hiring history and no applicant counts.
